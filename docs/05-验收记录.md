# 05 验收记录

验收工具（B3）：

- 程序内置自检：`MeiliTerminal.exe --smoke [--smoke-offline] [--smoke-report <文件>] [--data-dir <目录>]`。
  - 用真实的组装和真实窗口跑，但窗口放在屏幕外、不激活、不进任务栏，也不发通知。
  - 依次检查：数据目录可写、设置读写、SQLite 缓存（含原生库）、中英字典、9 个页面逐一加载且无未处理异常、键盘精灵。
  - 联网部分（可用 `--smoke-offline` 跳过）：报价、日 K、期权链、IV、^IRX 利率。联网失败只记“警告”，因为机器可能本来就离线。
  - 写出 JSON 报告。退出码 0 表示没有失败，1 表示有失败，2 表示自检本身崩溃。
- 验收脚本：`build\acceptance.ps1 [-Exe <exe>] [-Portable] [-Offline]`。
  - 检查 exe 文件属性：原始文件名、产品名、公司名都不能含 tyu。
  - 在 `scratch\acceptance\<时间>` 下用一次性数据目录跑自检。加 `-Portable` 时再验证“exe + portable.flag”布局：数据要写在 exe 旁边。
  - 生成 `acceptance.md`。超时会结束进程，只结束本次启动的进程。
