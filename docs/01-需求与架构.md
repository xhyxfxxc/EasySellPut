# tyuStockApp：需求与架构（第 1 阶段）

> 版本 0.1 · 2026-11-10 · 所有开发材料只放在 `C:\tyuStockApp`
> 本文的数据源结论都来自 2026-11-10 19:50–20:20（北京时间，美东盘前 06:50–07:20 ET）在本机实际发出的请求，原始响应可用 `tools\probes\probe_sources.py` 重新生成。

## 1. 需求（已与用户确认）

| 类别 | 需求 |
|---|---|
| 平台 | Windows 11 原生桌面应用，不依赖浏览器/WebView 运行 |
| 数据 | 接入多个**免费、无需账户/API Key** 的美股股票、ETF、期权数据源；源之间自动故障切换 |
| 实时性 | 免费源能给到多实时就多实时（报价尽量实时，期权一般为 15 分钟延迟） |
| 行情 | 实时/延迟报价，盘前盘后，自选股列表 |
| 图表 | K 线（分时、日/周/月等周期）+ 技术指标 |
| 期权 | 期权链与报价；隐含波动率（IV）与希腊值；成交量与未平仓量（OI）；简单期权策略盈亏图 |
| 其他 | 价格提醒 + Windows 桌面通知；新闻和基本面数据；导出 CSV / Excel |
| 界面 | 中英文可切换；深色/浅色可切换；要非常好用、易用 |
| 交付 | 安装包 + 免安装（便携）版 |

非功能要求：启动快、滚动和图表流畅；网络差时不卡界面；单个数据源失效不影响使用；不需要管理员权限即可安装和运行。

| 层面 | 选择 | 理由 |

## 4. 架构

### 4.1 分层

```
┌──────────────────────────── Meili.App (WPF, net10.0-windows) ───────────────────────────────┐

│ App Services：ThemeService · LocalizationService · NotificationService(Toast+托盘)              │
│               DialogService · ExportService(CSV/XLSX) · AlertMonitor(后台) · RefreshScheduler   │
└───────────────────────────────────────────┬──────────────────────────────────────────────────┘
                                            │ 只依赖接口
┌──────────────────────────── Meili.Core (net10.0, 无 UI 依赖) ────────────────────────────────┐
│ Domain：Symbol · Quote · Bar · OptionContract · OptionChain · Fundamentals · NewsItem · Alert │
│ 接口：IQuoteService · IHistoryService · IOptionsService · IFundamentalsService · INewsService  │
│       ISymbolSearch · ISettingsStore · IWatchlistStore · IAlertStore                          │
│ 计算：Indicators(包装 Skender) · BlackScholes/IV/Greeks · StrategyPayoff · MarketCalendar(美东/夏令时) │
└───────────────────────────────────────────┬──────────────────────────────────────────────────┘
┌──────────────────────────── Meili.Data (net10.0) ────────────────────────────────────────────┐
│ Providers（每个源一个类，实现能力接口子集）：Yahoo · Cboe · Nasdaq · Cnbc · Sec · Sina · Tencent · Eastmoney │
│ FailoverRouter：按能力维护有序提供者列表 + 健康评分 + 熔断；结果标注来源和延迟                     │
│ HttpLayer：HttpClientFactory · 浏览器头 · 代理模式(系统/直连/手动) · Polly 重试/超时 · 每源限速    │
│ Cache：内存 (短 TTL 报价) + SQLite (K 线、基本面、期权链快照) · 请求合并(同一请求只发一次)          │
│ Stores：JSON 设置/自选/提醒（%LOCALAPPDATA%\EasySellPut，便携模式下为 exe 同目录 data\）          │

```

依赖方向：App → Core ← Data（App 在组合根里注册 Data 实现）。Core 不引用任何网络或 UI 库，方便单测。

### 4.2 数据访问与故障切换

- **能力接口**：Quote、IntradayBars、DailyBars、OptionExpirations、OptionChain、Fundamentals、Financials、News、SymbolSearch。每个 Provider 声明自己支持哪些能力。
- **FailoverRouter**：对每种能力维护一个有序列表（见第 5.3 节）。调用时依次尝试；失败（超时/HTTP 错误/解析失败/空数据/明显异常值，如盘前 Yahoo 期权 IV=1e-5）就记一次失败并换下一个源。连续失败 N 次的源熔断 1–5 分钟，期间跳过，再用半开状态试探恢复。
- **结果元数据**：每条数据都带 `Source`、`AsOf`（数据时间）、`IsRealtime/DelayMinutes`，界面上显示“来源 · 延迟”小标签，用户一眼能看出数据有多新。
- **刷新策略**（RefreshScheduler）：按美东交易时段自适应——盘中报价 2–5 秒，盘前盘后 10 秒，休市 60 秒；只刷新当前可见的标的；期权链 30–60 秒；窗口最小化时降频。多个标的报价合并成一次批量请求（Yahoo v7 / 新浪 / 腾讯 都支持一次查多个代码）。
- **代理**：本机装有 Clash Verge（见第 5.1 节）。设置页提供“跟随系统 / 直连 / 手动代理（如 http://127.0.0.1:45444）”三种模式，并有“测试所有数据源”按钮。
- **限速**：每个源独立的令牌桶（如 Yahoo ≤ 2 次/秒，Nasdaq ≤ 1 次/秒，SEC ≤ 5 次/秒，SEC 要求的 User-Agent 带联系邮箱）。

## 5. 数据源探测结果

### 5.1 网络与代理

| 检查项 | 结果 |
|---|---|
| WinHTTP 代理（`netsh winhttp show proxy`） | 直接访问，没有代理 |
| IE/系统代理（注册表 Internet Settings） | `ProxyEnable=0`（关闭），但 `ProxyServer=127.0.0.1:45444` 已填好，有本地地址例外列表 |
| 环境变量 / git / npm / pip 代理 | 都没有设置 |
| 本机 45444 端口 | **Clash Verge（verge-mihomo）正在监听** |
| 实测 | “直连”模式（不设代理）也能访问 Yahoo、Google、CBOE 等境外站点，说明 Clash 很可能开着 TUN/透明代理模式，所有流量其实都经过 Clash |

**结论与影响：**
1. 现在这台电脑上所有候选源都能访问，但这**依赖 Clash 开着**。我没有在 Clash 关闭的情况下测（不该动用户的代理软件）。在中国大陆如果 Clash 关掉，Yahoo / Google 很可能访问不了或很慢，CBOE / Nasdaq / SEC 不稳定；新浪、腾讯、东方财富是国内站点，应该仍能直连。
2. 所以故障切换链里必须保留国内源（新浪/腾讯/东方财富）作为报价和 K 线的兜底；设置页提供代理模式切换和一键测速。
3. 显式走 `127.0.0.1:45444` 时 CBOE 从 4–5 秒降到 1–2 秒（直连时 3.9–5.3 秒），但 SEC companyfacts 出现过一次 `SSL UNEXPECTED_EOF`；直连时一次快速连续请求里 Yahoo 也出现过一次同样的 SSL 握手中断。网络层要对这类错误自动重试。

## 6. 功能与界面规划（易用性要点）

- **主窗口**：左侧导航（自选 / 行情详情 / 图表 / 期权 / 策略 / 新闻与基本面 / 提醒 / 设置），顶部是全局搜索框（输入代码或公司名即可自动补全，回车打开），右上角快速切换主题和语言。
- **自选**：分组标签页；表格可排序、可拖动调整顺序；价格变化时闪烁高亮；双击进详情；右键菜单可设提醒、导出、删除。首次启动自带示例自选（SPY、QQQ、AAPL、MSFT、NVDA、TSLA），用户打开就有数据可看。
- **个股详情**：报价卡（现价、涨跌、盘前盘后、买卖价）+ K 线 + 关键指标 + 新闻，同一页能看完。
- **图表**：周期按钮（分时、1 分、5 分、15 分、1 小时、日、周、月），指标勾选（MA、EMA、BOLL、成交量、MACD、RSI、KDJ），十字光标显示 OHLC，滚轮缩放、拖动平移。
- **期权**：选到期日 → T 型报价表（左 Call 右 Put，中间行权价，价内底色区分，现价位置自动居中）；可显示/隐藏列（IV、Delta、Gamma、Theta、Vega、OI、成交量）；IV 微笑小图。
- **策略**：在期权表里点一下就能加入策略腿，或选模板（备兑看涨、牛市/熊市价差、跨式、宽跨式、铁鹰式）；画到期盈亏线和 T+n 曲线，标出盈亏平衡点、最大盈利/亏损。
- **状态栏**：每个数据源的健康灯（绿/黄/红）、当前美东时间和市场状态（盘前/盘中/盘后/休市）、数据来源和延迟。
- **约定**：默认“红涨绿跌”，可在设置里改；所有时间同时显示美东时间，悬停显示北京时间。

## 8. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 免费接口都是非官方接口，可能随时改格式、加验证或限流（Stooq、MarketWatch 已经被反爬挡住） | 某个功能突然没数据 | 多源故障切换；每个 Provider 解析做好容错；用 fixtures 回归测试；状态页让用户看到是哪个源坏了 |
| 境外数据源依赖本机 Clash 代理 | Clash 关掉后 Yahoo/CBOE/Nasdaq 可能用不了 | 保留新浪/腾讯/东方财富国内源兜底报价和 K 线；代理模式可配置；期权数据目前只有境外源，无代理时提示用户 |
| 网络偶发 SSL 握手中断（实测出现过） | 请求失败 | Polly 自动重试 + 换源 |
| Nasdaq 偶发 “Error while calling vendor” | 报价为空 | 识别 bCode 3002 当作失败并重试/换源 |
| 期权数据本身是 15 分钟延迟；盘前 Yahoo 的 IV 无效 | 用户误以为是实时 | 界面明确标“延迟 15 分钟”；过滤异常 IV 并本地重算 |
| CBOE 大文件（SPX 14 MB） | 卡顿、占内存 | 后台流式解析、缓存、只把当前到期日放进界面 |
| 时区和夏令时（美东 vs 北京） | 交易时段判断错误 | 用 `America/New_York`（Windows 上是 “Eastern Standard Time”）时区计算；内置美股节假日表 |
| 数据源使用条款通常限个人非商业使用 | 合规风险 | 定位个人自用工具；关于页加免责声明；不重新分发数据 |
| .NET 8 今天结束支持 | 安全更新停止 | 已改用 .NET 10 LTS（支持到 2028-11） |
| 没有代码签名证书 | 首次运行 SmartScreen 会提示“未知发布者” | 文档里说明；以后需要可以买证书签名 |
| 单文件 exe 约 70 MB 以上 | 下载体积大 | 开启压缩；安装包用 LZMA2；可选“依赖框架”的小体积版本 |
| 没有管理员权限 | 不能装系统级组件 | 工具链全部装在项目目录；安装包做成用户级安装 |
